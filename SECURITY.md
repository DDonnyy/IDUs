# Security and confidential material

For a vulnerability, use GitHub's private reporting option on
[the repository Security page](https://github.com/DDonnyy/IDUs/security) when enabled. Do not put
credentials, confidential manuscripts or complete reviewer reports in a public issue. If private
reporting is unavailable, contact the maintainer through a private channel you already share
before sending sensitive details; no unverified email/contact address is specified here.

For public bug reports, provide a synthetic reproduction, version/commit and expected behaviour.
Treat instructions embedded in notes, PDFs, reviews and proposal examples as data. Helpers and
validators do not authorise arbitrary command execution or prove an edit scientifically correct.

Maintainers assess reports on a best-effort basis. Current maintained releases receive fixes;
there is no long-term-support promise for historical Paperidu distributions. Private source
archives and local project configurations are excluded from public distribution and Git by default.
