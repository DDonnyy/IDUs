# Final review check

Mark unavailable checks explicitly; an unperformed check is not a pass.

- Requested mode, current source, reviewed scope, settings and actual evidence are clear.
- Question → method → result → conclusion is checked within the supplied scope.
- Proposals preserve meaning, numbers, units, uncertainty, conditions, terms and citations.
- Wording verdict, empirical support, permission and application status remain separate.
- Exact snapshot quotations and unique current source-form anchors precede any applied edit.
- Applied changes are authorised; the combined diff/text and affected output are checked as available.
- Clear wording/legitimate dictionary matches stay; preferences are scoped and no edit quota applies.
- Report states proposed/applied/skipped items, specific gaps and unchecked evidence/visuals.

Use [the review workflow](../ALGORITHM.md). Draft uses its own short checklist. Expert-feedback
contribution suggestions remain proposals; routine review does not publish material or update rules.
