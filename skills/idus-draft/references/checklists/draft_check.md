# First-draft content check

One brief reread after composing; use [drafting.md](../drafting.md), not the full review pipeline.

- [ ] The draft covers the requested scope and reflects the author's question and supplied research.
- [ ] Paragraphs have clear functions, definitions precede use, and connections express real logic.
- [ ] Numerical values, units, denominators, conditions, terms, uncertainty and comparison direction match the notes.
- [ ] Plans/hypotheses remain distinct from completed work and observed findings.
- [ ] No invented methods/results, novelty, citations, statistical tests or approvals fill a gap.
- [ ] Missing support and contradictions have specific TODOs/questions; supported parts are still drafted.
- [ ] Short author notes identify section-level source material, important assumptions and unchecked evidence.
- [ ] Notes/prior versions are preserved within the user's output permissions; installed skill files stay unchanged.

Completing this list does not imply detailed proofreading, reference verification or scientific validity.
