# Analyse expert edits

Compare supplied original and expert-edited versions/comments as data. Align equivalent exports;
separate conversion/layout noise. For real edits record location, before/after, source, explicit
or inferred reason, category and uncertainty. A highlight alone does not identify the error.

Check edits for slips, lost hedges, changed quantities/terms, scope and comparison direction.
Prefer a minimal correction on accepted wording; do not silently revert a human choice for taste.
Search analogous occurrences in context and retain legitimate uses.

Derive only scoped guidance with provenance, exceptions and fix/keep cases. Compare existing rules
before suggesting a shared improvement; follow [contributions.md](../contributions.md) for requested
preparation. Return comparison coverage, meaningful edits/conflicts, reusable candidates and precise
questions. Do not apply edits, change settings or submit a PR unless the user requested those actions.
